Инструкция пользователя «Внешний мозг»

«Внешний мозг» — список дел как в Google Keep: задачи строками, группы — отступом. Плюс поиск, оценка времени, отмена изменений и страховка копиями. Работает без интернета, устанавливается без Play Market.

Открыть: https://russkin.github.io/external-brain/

Установка

  1. На телефоне откройте https://russkin.github.io/external-brain/ (проверяется на Android и iPhone; планшет — «как получится»).
  2. Android Chrome → меню ⋮ → «Добавить на главный экран». iPhone Safari → кнопка «Поделиться» → «На экран “Домой”».
  3. Дальше открывайте приложение ярлыком — список виден сразу, интернет не нужен.

Новая задача — пять способов

  1. Список пуст (первый запуск). Внизу есть пустое поле: наберите текст и нажмите Enter (или просто тапните мимо) — задача создана. Такое поле внизу бывает только пока задач нет или почти нет.
  2. Enter в конце задачи — новое поле под ней.
  3. Enter в начале задачи — новое поле над ней.
  4. Enter в середине задачи — строка делится на две: хвост от курсора становится новой задачей ниже.
  5. Enter в пустом поле — задача без текста (заполните её позже или удалите Backspace'ом).

Редкие способы (поле с набранным текстом): Backspace в начале набранного — задача создаётся, курсор уходит в задачу выше; потянуть поле за точки — станет задачей; свайпнуть строку с набранным текстом влево — текст станет задачей и сразу отметится выполненной.

Выполнить и вернуть

  • Проведите по задаче влево — зелёный флаг «✓ Выполнено». Задача зачеркнётся и уедет вниз, в раздел «Выполнено».
  • Ошиблись — проведите по выполненной влево и нажмите «↩ Не выполнено», задача вернётся обратно (если выполняли группу — вернётся вся группа).
  • Тап по раскрытой строке закрывает флаг обратно.
  • Выполненные задачи не перетаскиваются.

Группы

  • Потяните задачу за точки ⠿ вверх/вниз — она переедет. Родитель переезжает вместе с вложенными.
  • Потяните за точки вправо/влево — задача войдёт в группу верхней или выйдет из неё (тоже вместе с вложенными). В группу — только сдвигом, пока тянете страница стоит на месте.
  • Тап по «Выполнено · N» — показать/скрыть выполненные (N — всегда все).
  • Тапните по точкам родителя — вложенные спрячутся; тапните ещё раз — покажутся. Кнопки 📁 и 📂 вверху прячут и показывают всё сразу, включая раздел выполненных.
  • Вложенность видна отступом и оттенком поля.

Время задачи

Проведите по задаче вправо (или тапните метку в углу поля) — откроется окно со стрелками «Часы» и «Минуты». «Убрать» снимает метку, «Отмена» ничего не меняет. Время видно меткой в правом нижнем углу задачи, например 1ч 30м. У родителя метка считается сама — сумма времени вложенных (выполненные не считаются). Если раскрыт флаг «✓ Выполнено» — свайп вправо только закроет флаг.

Поиск

Кнопка 🔍 вверху открывает внизу окно: поле + кнопки Поиск / Отмена / Вверх / Вниз + счётчики («Совпадений: 5», «2/5»). При пустом поле Поиск, Вверх и Вниз неактивны. Наберите текст и нажмите Поиск — страница прыгнет к первой найденной задаче (ищется везде, свёрнутое разворачивается, большие/маленькие буквы и ё/е не важны). Найденная подсвечена зелёным. Кнопки Вверх/Вниз ходят по совпадениям. Кнопка Enter на клавиатуре — то же, что Поиск. Отмена закрывает окно: если ничего не искали — страница вернётся назад, если искали — останется на найденной.

Отмена изменений

Стрелки ↩ ↪ вверху отменяют и возвращают последнее изменение (помнят 50 шагов, работают даже после перезагрузки приложения).

Копии — страховка от потери

Всё хранится в браузере телефона. Если телефон потеряется — данные пропадут. Поэтому есть копии:

  • Скользящая копия делается сама при каждом сохранении. Пункт меню «♻ Восстановить копию задач».
  • Постоянная копия — «вечная» точка: кнопка «💾 Сделать постоянную копию» (только с вашего подтверждения; в копию попадают только задачи, без настроек и токена), сама создаётся при первом запуске новой версии. Восстановление — «♻ Восстановить постоянную копию».
  • Даты обеих копий видны в диагностике (ⓘ).
  • Для надёжности включите синхронизацию (ниже) — тогда список живёт ещё и в облаке.

Значки вверху экрана

Верхний ряд: название и версия, ⇅ интернет (зелёный — есть сеть, серый — нет; рядом скорость, на iPhone пусто), квадратик-светофор (тап — отправить вручную), ⚙ меню. Светофор: зелёный — всё отправлено, жёлтый мигает — отправляется, красный — ошибка, серый — синк выключен. Красный «!» — версии разошлись: тапните, чтобы отправить ещё раз. Нижний ряд: 🔍 поиск, 📁 спрятать всё, 📂 показать всё, ↩ отменить, ↪ вернуть, 🗑 удалить выполненные. Внизу экрана строка: сколько задач, сколько выполнено, состояние синка.

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться списком, 🔗 Поделиться приложением, 📖 Инструкция (эта страница, работает без интернета), Удалить выполненные, 💾 Резервная копия (раскрывается: копии ниже).
  • ♻ Восстановить копию задач, 💾 Сделать постоянную копию, ♻ Восстановить постоянную копию — про копии написано выше.
  • 🔑 Репозиторий и токен — после предупреждения «для администратора» окно по центру: owner/repo + GitHub token (только на этом устройстве), «Сохранить» и «Отмена».

Синхронизация (необязательно)

Без неё всё работает на одном телефоне — этого достаточно. Синк нужен для двух вещей: страховка списка в облаке и перенос на новый телефон. Включение (один раз): ⚙ → «🔑 Репозиторий и токен» → подтвердите предупреждение → введите owner/repo и GitHub token → «Сохранить» → «⇅ Синхронизировать». Дальше само: отправка через пару секунд после каждого изменения, при открытии и раз в минуту, пока вкладка открыта. Кто позже изменил задачу — тот и прав. Пустой телефон общий список не стирает. Новый телефон: поставьте приложение, введите те же repo и токен, нажмите «⇅ Синхронизировать». При ошибке синка приложение само отправляет журнал ошибок на сервер в папку logs/ (только служебные данные, без текстов задач), не чаще раза в 15 минут.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома.
  • После обновления выглядит по-старому — сверьте версию вверху экрана и обновите страницу дважды.
  • На новом телефоне пусто — нажмите «⇅ Синхронизировать».
  • Светофор красный «!» — тапните по нему.
  • Светофор долго жёлтый — слабая сеть, просто подождите.
  • Не вводится текст (iPhone) — обновите приложение до свежей версии.
  • Ошибка синка вида «Returned response is null» — обновите приложение.
