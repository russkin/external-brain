Инструкция пользователя «Внешний мозг»

Простой список дел: задачи — строками, группы — отступом, выполненное — свайпом. Работает офлайн, устанавливается без Play Market.

Установка

  1. Откройте https://russkin.github.io/external-brain/
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
  3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

Главный экран

Каждая строка: слева точки, правее — поле задачи (многострочное). Новая задача — через Enter в строке: пустое поле встаёт под ней; у родителя с дочерними — сразу на их уровне (новая станет ещё одной дочерней), у обычной задачи — на её уровне (набрали + Enter — задача встала туда же, поле поехало ниже). Если курсор в начале текста задачи — Enter вставляет пустое поле над ней на её же отступе; в середине — делит строку: левая часть остаётся без перенесённого хвоста (лишний пробел в конце срезается), хвост от каретки до конца становится новой задачей ниже, курсор встаёт в её начало. Backspace с курсором в начале сцепляет задачу с предыдущей: текст приклеивается к верхней с пробелом, текущая строка удаляется, курсор встаёт между пробелом и перенесённым текстом. Backspace, когда текст строки уже удалён полностью, — строка просто исчезает, курсор уходит в конец предыдущей (удалённый текст никуда не копируется). Набрали текст и просто убрали фокус (тап мимо, свернули клавиатуру) — задача создаётся так же, без Enter; поле после этого гаснет, новое вызывается Enter в любой строке. Если в другом месте уже набран незавершённый текст — Enter в строке сначала создаёт эту задачу на её прежнем месте (иначе поле просто переезжает сюда), и только потом открывает новое поле под строкой. Тапы по строкам, флагам и точкам — их собственные жесты, они поле не трогают. При пустом списке или одной задаче пустое поле всегда внизу и так. Пустое поле тоже умеет: свайп-флаг ✓, сдвиг за точки, перетаскивание (при переносе встаёт на отступ соседа сверху, как задачи), Backspace в начале набранного — как потеря фокуса: задача создаётся, а курсор переезжает в задачу сверху; в пустом поле — убрать его вниз.

  • Точки — перетаскивание вверх/вниз (родитель едет с вложенными). Захват точек у поля с текстом сразу создаёт задачу; поле теряет фокус, набранный текст не теряется. Перестановка (место и отступ) пишется в историю: ↩ возвращает задачу (и пустое поле) на место. Клавиатура закрывается ПОСЛЕ жеста (закрывать сразу — вьюпорт прыгал, страница уезжала из-под пальца и сдвиг сбивался); курсор в конец поля возвращается только после переноса самого этого поля, чужой жест (свайп родителя) фокус не возвращает.
  • Точки — сдвиг вправо/влево: задача входит в группу верхней или выходит из неё. Пока тянете — страница стоит на месте, сдвиг идёт от пальца.
  • Тап по точкам родителя — свернуть/развернуть вложенные. Выполненные дети в группе прячутся вместе с остальными (последняя дочерняя не висит под свёрнутым родителем), счётчик «Выполнено» показывает видимые.
  • Тап по разделителю «Выполнено · N» — скрыть/показать все выполненные разом. Состояние запоминается на устройстве; разделитель остаётся (со стрелкой ▸ / ▾) — по нему же возвращаете список обратно.
  • Свайп строки справа налево — флаг «✓ Выполнено»: родитель уводит всю ветку (дети тоже отмечаются и переезжают вместе с ним). Набранное в поле внутри ветки создаётся и уходит в выполненные вместе с ней; сам свайп сразу снимает фокус с полей — клавиатура закрывается, текст поля не теряется. Выполненная спускается под поле ввода. Свайп выполненной — «↩ Не выполнено»: родитель возвращается вместе со всей веткой — дети возвращаются к нему в невыполненные. Ветка без живого родителя возвращается без отступа (вложенность внутри сохраняется). Выполненные не перетаскиваются.
  • Свайп строки слева направо — время задачи: модалка со стрелками «Часы −/+» (шаг 60) и «Минуты −/+» (шаг 5). «Убрать» снимает метку, «Отмена» ничего не меняет. Заданное время видно меткой-наложением в правом нижнем углу поля задачи (например 30 м или 1ч 30м): пока текст поля до метки не доходит — её фон прозрачный, а если последняя строка заходит под метку — фон делается непрозрачным (цвета поля), чтобы надписи не слипались. Тап по метке открывает ту же модалку. У задачи без времени угол поля свободен. Если задача раскрыта свайпом влево (виден флаг «✓ Выполнено») — свайп вправо только закрывает флаг, модалка времени при этом не открывается.
  • Родителю время ставить нельзя (свайп и тап по метке модалку не открывают): его метка появляется сама, как только время задано хотя бы у одной задачи первого вложения, и равна сумме времени первого вложения (у вложенных-родителей — их такая же сумма). Без вложенных со временем у родителя метка исчезает, своё прежнее время в вёрстку не идёт.
  • ↩ ↪ в шапке — отмена/возврат последних изменений (история переживает перезагрузку и обновление приложения). Enter делится на два шага: сначала уходит новое пустое поле (задача остаётся), затем — сама задача. Создание по потере фокуса — один шаг: задача уходит, текст возвращается в поле. Вызов поля через Enter в строке — тоже шаг: отмена убирает поле и возвращает курсор в конец задачи.

Кнопки вверху

Верхний ряд: название + версия, ⇅ интернет, светофор синка, ⚙ меню. Нижний ряд: 📁 свернуть все, 📂 развернуть все, ↩ ↪ история, 🗑 удалить выполненные (окно подтверждения — только если есть что удалять).

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться, Удалить выполненные, ♻ Восстановить копию задач, 💾 Сделать постоянную копию, ♻ Восстановить постоянную копию.
  • 🔑 Репозиторий и токен — после предупреждения «для администратора»: owner/repo + GitHub token (только на этом устройстве), «Сохранить».

Синхронизация (необязательно)

На каждом устройстве: ⚙ → owner/repo + token → «Сохранить» → «⇅ Синхронизировать». Дальше само: отправка через 2 сек после изменений, при открытии и раз в минуту. Кто позже изменил — тот и прав; пустое устройство общий список не стирает.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома (страница и данные в кэше).
  • После обновления выглядит по-старому — сверьте версию вверху экрана, обновите страницу дважды.
  • На новом устройстве пусто — «⇅ Синхронизировать», проверьте строку статуса.
