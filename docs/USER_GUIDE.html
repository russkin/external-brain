Инструкция пользователя «Внешний мозг»

Простой список дел: задачи — строками, группы — отступом, выполненное — свайпом. Работает офлайн, устанавливается без Play Market.

Установка

  1. На телефоне откройте https://russkin.github.io/external-brain/ (проверяется только на Android; планшет и iPhone — «как получится», без гарантий).
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
  3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

Главный экран

Каждая строка: слева точки, правее — поле задачи (многострочное). Новая задача — через Enter в строке: пустое поле встаёт под ней; у родителя с дочерними — сразу на их уровне (новая станет ещё одной дочерней), у обычной задачи — на её уровне (набрали + Enter — задача встала туда же, поле поехало ниже). Enter в ещё пустом поле создаёт задачу без текста: такая пустая строка остаётся в списке (заполните её позже или удалите Backspace'ом). Если курсор в начале текста задачи — Enter вставляет пустое поле над ней на её же отступе; в середине — делит строку: левая часть остаётся без перенесённого хвоста (лишний пробел в конце срезается), хвост от каретки до конца становится новой задачей ниже, курсор встаёт в её начало. Backspace с курсором в начале сцепляет задачу с предыдущей: текст приклеивается к верхней с пробелом, текущая строка удаляется, курсор встаёт между пробелом и перенесённым текстом. Backspace, когда текст строки уже удалён полностью, — строка просто исчезает, курсор уходит в конец предыдущей (удалённый текст никуда не копируется). Backspace в строке, которая и так пустая, — она удаляется, курсор тоже уходит в конец предыдущей. Набрали текст и просто убрали фокус (тап мимо, свернули клавиатуру) — задача создаётся так же, без Enter; пустое поле по тому же правилу: тап мимо с пустым полем создаёт пустую задачу (заполните её позже или удалите Backspace'ом); когда приложение само снимает фокус (например, отметили задачу выполненной), пустую не плодит. Новое поле вызывается Enter в любой строке. Если в другом месте уже набран незавершённый текст — Enter в строке сначала создаёт эту задачу на её прежнем месте (иначе поле просто переезжает сюда), и только потом открывает новое поле под строкой. Тапы по строкам, флагам и точкам — их собственные жесты, они поле не трогают. Отдельного пустого поля при длинном списке нет. При пустом списке или одной задаче пустое поле всегда внизу и так. Пустое поле тоже умеет: свайп-флаг ✓, сдвиг за точки, перетаскивание (при переносе встаёт на отступ соседа сверху, как задачи; и задача, проехавшая через поле, забирает его за собой), Backspace в начале набранного — как потеря фокуса: задача создаётся, а курсор переезжает в задачу сверху; в пустом поле — убрать его вниз. Цепочка вниз: дети набираются подряд с тем же отступом.

  • Точки — перетаскивание вверх/вниз (родитель едет с вложенными). Захват точек у поля с текстом сразу создаёт задачу; поле теряет фокус, набранный текст не теряется. Перестановка (место и отступ) пишется в историю: ↩ возвращает задачу (и пустое поле) на место. Клавиатура закрывается ПОСЛЕ жеста (закрывать сразу — вьюпорт прыгал, страница уезжала из-под пальца и сдвиг сбивался); курсор в конец поля возвращается только после переноса самого этого поля, чужой жест (свайп родителя) фокус не возвращает.
  • Точки — сдвиг вправо/влево: задача входит в группу верхней или выходит из неё. Новое поле всегда начинается без отступа; в группу входит только сдвигом за точки. Уровень вложения виден отступом и оттенком поля. Пока тянете — страница стоит на месте, сдвиг идёт от пальца.
  • Тап по точкам родителя — свернуть/развернуть вложенных живых. Точечное сворачивание действует только на живой список. Кнопки 📁/📂 в шапке сворачивают и разворачивают всё включая секцию. Счётчик «Выполнено» показывает всех выполненных.
  • Тап по разделителю «Выполнено · N» — показать/скрыть секцию выполненных. Живые ветки тап не трогает. Состояние запоминается на устройстве; разделитель остаётся (со стрелкой ▸ / ▾) — по нему же возвращаете список обратно. Разделитель на месте, пока есть хоть один выполненный; N — всегда все выполненные.
  • Свайп строки справа налево — флаг «✓ Выполнено»: родитель уводит всю ветку (дети тоже отмечаются и переезжают вместе с ним). Набранное в поле внутри ветки создаётся и уходит в выполненные вместе с ней; сам свайп сразу снимает фокус с полей — клавиатура закрывается, текст поля не теряется. Выполненная спускается под поле ввода (новые — выше старых). Свайп выполненной — «↩ Не выполнено»: родитель возвращается вместе со всей веткой — дети возвращаются к нему в невыполненные. Ветка без живого родителя возвращается без отступа (вложенность внутри сохраняется) и без зачёркивания. Выполненные не перетаскиваются.
  • Свайп строки слева направо — время задачи: модалка со стрелками «Часы −/+» (шаг 60) и «Минуты −/+» (шаг 5). «Убрать» снимает метку, «Отмена» ничего не меняет. Заданное время видно меткой-наложением в правом нижнем углу поля задачи (например 30 м или 1ч 30м): пока текст поля до метки не доходит — её фон прозрачный, а если последняя строка заходит под метку — фон делается непрозрачным (цвета поля), чтобы надписи не слипались. Тап по метке открывает ту же модалку. У задачи без времени угол поля свободен. Если задача раскрыта свайпом влево (виден флаг «✓ Выполнено») — свайп вправо только закрывает флаг, модалка времени при этом не открывается.
  • Родителю время ставить нельзя (свайп и тап по метке модалку не открывают): его метка появляется сама, как только время задано хотя бы у одной задачи первого вложения, и равна сумме времени первого вложения (у вложенных-родителей — их такая же сумма). Выполненные вложения в сумму не входят: отметили задачу выполненной — её время вышло из метки родителя. Без вложенных со временем у родителя метка исчезает, своё прежнее время в вёрстку не идёт.
  • ↩ ↪ в шапке — отмена/возврат последних изменений (50 шагов, история переживает перезагрузку и обновление приложения). Enter делится на два шага: сначала уходит новое пустое поле (задача остаётся), затем — сама задача. Создание по потере фокуса — один шаг: задача уходит, текст возвращается в поле. Вызов поля через Enter в строке — тоже шаг: отмена убирает поле и возвращает курсор в конец задачи.

Кнопки вверху

Верхний ряд: название + версия, ⇅ интернет (зелёный — есть сеть, серый — нет; рядом скорость в МБ/с, на iPhone пусто), светофор синка (тап — отправить вручную; красный «!» — конфликт версий, тап отправляет ещё раз), ⚙ меню. Нижний ряд: 🔍 поиск, 📁 свернуть все, 📂 развернуть все, ↩ ↪ история, 🗑 удалить выполненные (окно подтверждения — только если есть что удалять). Внизу — строка статуса: счётчики + состояние синка.

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться списком, 🔗 Поделиться приложением, 📖 Инструкция (эта страница, офлайн), Удалить выполненные, 💾 Резервная копия (раскрывается: копии ниже).
  • ♻ Восстановить копию задач — возврат к состоянию до последнего сохранения (скользящая копия делается сама при каждой записи; дата видна в диагностике; отменить восстановление — стрелкой ↩).
  • 💾 Сделать постоянную копию — «вечная» точка (только задачи, без настроек и токена; перезапись только с подтверждением; сама создаётся при первом запуске новой версии; дата и происхождение — в диагностике).
  • ♻ Восстановить постоянную копию — возврат к «вечной» точке (с подтверждением; отменить — стрелкой ↩).
  • 🔑 Репозиторий и токен — после предупреждения «для администратора» окно по центру: owner/repo + GitHub token (только на этом устройстве), «Сохранить» и «Отмена».

Синхронизация (необязательно — для бэкапа и переноса)

Приложение рассчитано на один телефон: без синка всё работает локально и офлайн. Синк — страховка в облаке и перенос на новый телефон: ⚙ → owner/repo + token → «Сохранить» → «⇅ Синхронизировать». Дальше само: отправка через 2 сек после изменений, при открытии и раз в минуту, пока вкладка открыта. Кто позже изменил — тот и прав; пустое устройство общий список не стирает. На новом телефоне введите те же repo и токен и нажмите «⇅ Синхронизировать». При ошибке синка приложение само отправляет журнал ошибок на сервер в папку logs/ (только служебные данные, без текстов задач), не чаще раза в 15 минут.

Поиск

Кнопка 🔍 в шапке: внизу открывается окно (поле + Поиск / Отмена / Вверх / Вниз + счётчики «Совпадений: N» и «2/5»). При пустом поле Поиск, Вверх и Вниз неактивны. Наберите текст, нажмите Поиск — клавиатура спрячется, страница прыгнет к первой найденной задаче (ищется везде, свёрнутое разворачивается, регистр не важен, ё = е). Задача — посередине между шапкой и окном, с зелёным контуром (окно приподнимается над клавиатурой). Вверх/Вниз ходят по совпадениям. Отмена без поиска возвращает страницу на место; после найденного — оставляет.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома (страница и данные в кэше).
  • После обновления выглядит по-старому — сверьте версию вверху экрана, обновите страницу дважды.
  • На новом устройстве пусто — «⇅ Синхронизировать», проверьте строку статуса.
  • Светофор показывает красный «!» — тапните по нему, чтобы отправить вручную.
  • Светофор долго жёлтый — дело в слабой сети, просто подождите.
