Инструкция пользователя «Внешний мозг»

Простой список дел по «Джедайским техникам»: собирай всё в инбокс, проясняй, каждый день съедай лягушку, слонов режь на бифштексы.

Установка

  1. Откройте https://russkin.github.io/external-brain/
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
  3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

Главный экран

  • Фокус дня (синяя рамка) — главная задача: сначала лягушка, иначе первое следующее действие, иначе первый инбокс.
  • Строка ввода + «В инбокс» — любая мысль сразу сюда (Enter тоже работает). Правило: инбокс к вечеру — пустой.
  • Инбокс — кнопки: Next (следующее), Wait (жду), Someday (когда-нибудь), Proj (проект → в следующие), X (удалить).
  • Следующие — Frog/Unfrog (лягушка дня), +1 (съесть бифштекс), Slices (нарезать слона), X. Галочка — готово.
  • Ожидание и Когда-нибудь — вернуть в следующие или удалить.
  • Готово — последние 30 выполненных: вернуть (Reopen) или удалить.

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться, Удалить выполненные.
  • Настройки синхронизации: owner/repo + GitHub token (только на этом устройстве), «Сохранить».

Лягушки и слоны

  • Лягушка — самая неприятная задача дня (кнопка Frog): первая в списке и в фокусе. Съешьте с утра.
  • Слон — задача больше 1–2 часов: Slices → число кусков, +1 съедает по куску, последний закрывает задачу сам.
  • Еженедельный обзор: «Когда-нибудь» и «Ожидание» → часть в следующие, часть удалить. Инбокс — в ноль.

Синхронизация (необязательно)

На каждом устройстве: ⚙ → owner/repo + token → «Сохранить» → «⇅ Синхронизировать». Дальше само: отправка через 2 сек после изменений, при открытии и раз в минуту. Кто позже изменил — тот и прав; пустое устройство общий список не стирает.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома (страница и данные в кэше).
  • После обновления выглядит по-старому — сверьте версию вверху экрана, обновите страницу дважды.
  • На новом устройстве пусто — «⇅ Синхронизировать», проверьте строку статуса.
