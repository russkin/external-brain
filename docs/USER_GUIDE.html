Инструкция пользователя «Внешний мозг»

Простой список дел: задачи — строками, группы — отступом, выполненное — свайпом. Работает офлайн, устанавливается без Play Market.

Установка

  1. Откройте https://russkin.github.io/external-brain/
  2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
  3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

Главный экран

Каждая строка: слева точки, правее — поле задачи (многострочное). Новая задача — через Enter в строке: пустое поле встаёт под неё на том же уровне (набрали + Enter — задача встала туда же, поле поехало ниже). Набрали текст и просто убрали фокус (тап мимо, свернули клавиатуру) — задача создаётся так же, без Enter; поле после этого гаснет, новое вызывается Enter в любой строке. Тапы по строкам, флагам и точкам — их собственные жесты, они поле не трогают. При пустом списке или одной задаче пустое поле всегда внизу и так. Пустое поле тоже умеет: свайп-флаг ✓, сдвиг за точки, перетаскивание (при переносе встаёт на отступ соседа сверху, как задачи), Backspace в пустом поле — убрать его вниз.

  • Точки — перетаскивание вверх/вниз (родитель едет с вложенными). Перестановка (место и отступ) пишется в историю: ↩ возвращает задачу (и пустое поле) на место.
  • Точки — сдвиг вправо/влево: задача входит в группу верхней или выходит из неё.
  • Тап по точкам родителя — свернуть/развернуть вложенные.
  • Свайп строки справа налево — флаг «✓ Выполнено»: родитель уводит всю ветку (дети тоже отмечаются и переезжают вместе с ним). Выполненная спускается под поле ввода. Свайп выполненной — «↩ Не выполнено»: родитель возвращается вместе со всей веткой — дети возвращаются к нему в невыполненные. Ветка без живого родителя возвращается без отступа (вложенность внутри сохраняется). Выполненные не перетаскиваются.
  • ↩ ↪ в шапке — отмена/возврат последних изменений. Enter делится на два шага: сначала уходит новое пустое поле (задача остаётся), затем — сама задача. Создание по потере фокуса — один шаг: задача уходит, текст возвращается в поле. Вызов поля через Enter в строке — тоже шаг: отмена убирает поле и возвращает курсор в конец задачи.

Кнопки вверху

Верхний ряд: название + версия, ⇅ интернет, светофор синка, ⚙ меню. Нижний ряд: 📁 свернуть все, 📂 развернуть все, ↩ ↪ история, 🗑 удалить выполненные.

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться, Удалить выполненные.
  • Настройки синхронизации: owner/repo + GitHub token (только на этом устройстве), «Сохранить».

Синхронизация (необязательно)

На каждом устройстве: ⚙ → owner/repo + token → «Сохранить» → «⇅ Синхронизировать». Дальше само: отправка через 2 сек после изменений, при открытии и раз в минуту. Кто позже изменил — тот и прав; пустое устройство общий список не стирает.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома (страница и данные в кэше).
  • После обновления выглядит по-старому — сверьте версию вверху экрана, обновите страницу дважды.
  • На новом устройстве пусто — «⇅ Синхронизировать», проверьте строку статуса.
