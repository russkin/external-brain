Инструкция пользователя «Внешний мозг»

«Внешний мозг» — список дел: задачи строками, группы — отступом. Плюс поиск, оценка времени, отмена изменений и страховка копиями. Работает без интернета — список хранится прямо в телефоне (в скрытом хранилище браузера). Для страховки есть резервное копирование списка на сервер GitHub: укажите в приложении репозиторий и токен (пункт меню «🔑 Репозиторий и токен»). Копия пригодится при потере или смене телефона.

Открыть: https://russkin.github.io/external-brain/

Установка

  1. На телефоне откройте https://russkin.github.io/external-brain/ (проверяется на Android и iPhone; планшет — «как получится»).
  2. Android Chrome → меню ⋮ → «Добавить на главный экран». iPhone Safari → кнопка «Поделиться» → «На экран “Домой”».
  3. Дальше открывайте приложение ярлыком — список виден сразу, интернет не нужен.

Новая задача — пять способов

  1. Список пуст (первый запуск). Есть пустая строка: наберите текст прямо в ней — задача уже создана, текст сохраняется сам.
  2. Enter в конце задачи — новая пустая строка под ней, курсор в неё.
  3. Enter в начале задачи — новая пустая строка над ней.
  4. Enter в середине задачи — строка делится на две: хвост от курсора становится новой задачей ниже.
  5. Пустая строка — задача без текста (заполните её позже, удалите Backspace'ом или кнопкой «✕ Удалить» справа от строки).

Потеря фокуса (тап мимо, сворачивание клавиатуры) ничего не создаёт — строка уже задача, набранное сохраняется само.

Выполнить и вернуть

  • Проведите по задаче влево — откроются два флага: зелёный «✓ Выполнено» и красный «✕ Удалить». Задача зачеркнётся и уедет вниз, в раздел «Выполнено».
  • Ошиблись — проведите по выполненной влево и нажмите «↩ Не выполнено», задача вернётся обратно (если выполняли группу — вернётся вся группа).
  • Тап по раскрытой строке закрывает флаг обратно.
  • Выполненные задачи не перетаскиваются.

Удаление задач

  • Красный флаг — проведите по задаче влево и нажмите «✕ Удалить». Спросит подтверждение. Работает и для выполненных. На пустой строке красного флага нет — там только зелёный «✕ Удалить», сносит сразу.
  • Выполненные — кнопка 🗑 вверху или пункт меню «Удалить выполненные». Спросит подтверждение; если выполненных нет — ничего не произойдёт.
  • Обычная строка — поставьте курсор в самое начало и нажмите Backspace: текст приклеится к задаче выше, а сама строка удалится.
  • Пустая строка — Backspace в ней же: строка просто удаляется.
  • Если вы стёрли весь текст, а потом нажали Backspace — строка удалится, стёртое не вернётся.
  • Случайно удалили — стрелка ↩ вернёт всё обратно (удаление тоже отменяется).

Группы

  • Потяните задачу за точки ⠿ (родителя — за треугольник) вверх/вниз — она переедет. Родитель переезжает вместе с вложенными.
  • Потяните за точки вправо/влево (у родителя — за треугольник) — задача войдёт в группу верхней или выйдет из неё (тоже вместе с вложенными). В группу — только сдвигом, пока тянете страница стоит на месте. Свёрнутый родитель при этом разворачивается.
  • Тап по «Выполнено · N» — показать/скрыть выполненные (N — всегда все). Тоже отменяется стрелкой ↩.
  • Тапните по треугольнику родителя — вложенные спрячутся (треугольник станет остриём вправо ▶); тапните ещё раз — покажутся (остриё вниз ▼). У обычных задач без вложенных — точки ⠿; если вложенные все выполнены — тоже точки (треугольник — только пока есть что сворачивать). Кнопки 📁 и 📂 вверху прячут и показывают всё сразу, включая раздел выполненных.
  • Вложенность видна отступом и оттенком поля.

Планирование

Кнопка 📅 вверху открывает страницу планирования — отдельный список задач с датой. Обычный список планы не мешают: планы живут только на своей странице.

  • Создание: напишите название в поле «Новый план…», укажите дату ДД.ММ.ГГГГ и нажмите ＋ или Enter. Название и дата обязательны — если чего-то не хватает, подсветится красным то поле, которое пусто (название — первым), курсор сразу прыгнет туда; при наборе краска снимается сама. Черновик названия сохраняется: закроете страницу — текст вернётся.
  • Целевая — строка «Целевая:» под формой: выберите задачу обычного списка, в которую сработавший план положит свою дочку. Выбор хранится только на этом устройстве (на втором телефоне — задайте заново). Пока целевая не выбрана (или стала выполненной/удалённой), сработавшие планы просто ждут — ничего не пропадает.
  • Час — строка «Срабатывает в:» под целевой: порог срабатывания в часах (0–23, по умолчанию 5 — то есть с 05:00). Неверное значение вернётся к разрешённому, смена часа сразу пересматривает ждущие планы.
  • Если целевая бита: пока планы наступают, а цель не выбрана или удалена — разово всплывает окно с кнопкой «Выбрать целевую» (ведёт прямо в список целей). Если целевая выполнена — вопрос: «Выбрать новую» или «Восстановить» (вернуть её и класть планы туда же). Пока окно закрыто — планы просто ждут, ничего не пропадает.
  • Срабатывание: когда наступает дата (порог — час из строки «Срабатывает в:», по умолчанию 05:00 утра), срабатывание происходит само — при открытии приложения, возврате на вкладку, появлении сети и раз в минуту в фоне. Просроченные планы (например, включили телефон на неделю позже) срабатывают сразу — по одному, сколько бы дней ни было пропущено.
  • Дочка: при срабатывании в целевую задачу последней добавляется строка «Название (ДД.ММ.ГГГГ)» и всплывает окно со списком всех сработавших планов (кнопка «Закрыть»). Кнопка ↩ отменяет: дочка уходит, план возвращается в ожидание. Смена даты плана даёт ему второй шанс сработать снова.
  • Строка показывает дату меткой в правом нижнем углу; у выполненной плана в метке стоит галочка.
  • Смена даты: проведите строку вправо — откроется окно с датой (маска ДД.ММ.ГГГГ, Enter — готово, «Отмена» — ничего не меняет). Пустая или неверная дата подсветится красным, окно не закроется — план без даты не бывает. С новой датой план получает второй шанс сработать (старая дочка, если была, остаётся обычной задачей).
  • Дальше всё как в обычном списке: «✓ Выполнено»/«↩ Не выполнено», «✕ Удалить» (с подтверждением), тап по тексту — правка, перетаскивание за точки ⠿ — порядок (планы плоские, без вложенности). Время (окно со стрелками «Часы»/«Минуты») на планах не предлагается.
  • ← возвращает к обычному списку с тем местом, где вы были. Шапка с этой стрелкой и кнопками ↩ ↪ ⓘ закреплена сверху — при прокрутке списка она не уезжает.

Время задачи

Проведите по задаче вправо (или тапните метку в углу поля) — откроется окно со стрелками «Часы» и «Минуты». «Убрать» снимает метку, «Отмена» ничего не меняет. Время видно меткой в правом нижнем углу задачи, например 1ч 30м. У родителя метка считается сама — сумма времени вложенных (выполненные не считаются), но галочку «Суммировать из вложенных» можно снять — тогда время ставится вручную, как у обычной задачи. Если раскрыт флаг «✓ Выполнено» — свайп вправо только закроет флаг.

Поиск

Кнопка 🔍 вверху открывает внизу окно: поле + кнопки Поиск / Отмена / Вверх / Вниз + счётчики («Совпадений: 5», «2/5»). При пустом поле Поиск, Вверх и Вниз неактивны. Наберите текст и нажмите Поиск — страница прыгнет к первой найденной задаче (ищется везде, свёрнутое разворачивается, большие/маленькие буквы и ё/е не важны). Найденная подсвечена зелёным. Кнопки Вверх/Вниз ходят по совпадениям. Кнопка Enter на клавиатуре — то же, что Поиск. Отмена закрывает окно: если ничего не искали — страница вернётся назад, если искали — останется на найденной.

Отмена изменений

Стрелки ↩ ↪ вверху отменяют и возвращают последнее изменение (помнят 50 шагов, работают даже после перезагрузки приложения). Отмена возвращает и сворачивание: свернули всё кнопкой 📁, нажали ↩ — группы и секция вернутся как были. Разворот одной группы тапом — тоже изменение: ↩ свернёт её обратно.

Копии — страховка от потери

Всё хранится в браузере телефона. Если телефон потеряется — данные пропадут. Поэтому есть копии:

  • Скользящая копия делается сама при каждом сохранении. Пункт меню «♻ Восстановить копию задач».
  • Постоянная копия — «вечная» точка: кнопка «💾 Сделать постоянную копию» (только с вашего подтверждения; в копию попадают только задачи, без настроек и токена), сама создаётся при первом запуске новой версии. Восстановление — «♻ Восстановить постоянную копию».
  • Даты обеих копий видны в диагностике (ⓘ).
  • Для надёжности включите синхронизацию (ниже) — тогда список живёт ещё и в облаке.

Значки вверху экрана

Верхний ряд: название и версия, ⇅ интернет (зелёный — есть сеть, серый — нет; рядом скорость, на iPhone пусто), квадратик-светофор (тап — отправить вручную), ⚙ меню. Светофор: зелёный — всё отправлено, жёлтый мигает — отправляется, красный — ошибка, серый — синк выключен. Знак «!» поверх квадратика: жёлтый — обычная ошибка (например, нет сети), белый — версии разошлись (конфликт). По любому «!» тапните, чтобы отправить ещё раз. Нижний ряд: 🔍 поиск, 📁 спрятать всё, 📂 показать всё, ↩ отменить, ↪ вернуть, 🗑 удалить выполненные. Внизу экрана строка: сколько задач, сколько выполнено, состояние синка.

Меню шестерёнки

  • ⓘ Информация для диагностики, ⇅ Синхронизировать, 📲 Установить, 📤 Поделиться списком, 🔗 Поделиться приложением, 📖 Инструкция пользователя (эта страница, работает без интернета), 📋 Информация о версиях (вся история, новое сверху), 🧹 Очистка (раскрывается: Удалить выполненные, Сжать удалённые), 💾 Резервная копия (раскрывается: копии ниже).
  • ♻ Восстановить копию задач, 💾 Сделать постоянную копию, ♻ Восстановить постоянную копию — про копии написано выше.
  • Сжать удалённые — записи об удалённых сжимаются в короткие метки (файл худеет). Сколько сжато — скажет строка состояния; сколько с текстом и сколько сжатых — диагностика (ⓘ, строка «Размер»). Спросит дважды; лучше сначала синкнуть все устройства. Отмена ↩ возвращает всё обратно.
  • 🔑 Репозиторий и токен — после предупреждения «для администратора» окно по центру: owner/repo + GitHub token (только на этом устройстве) + срок действия токена (необязательно, датой), «Сохранить» и «Отмена».

Синхронизация (необязательно)

Без неё всё работает на одном телефоне — этого достаточно. Синк нужен для двух вещей: страховка списка в облаке и перенос на новый телефон. Включение (один раз): ⚙ → «🔑 Репозиторий и токен» → подтвердите предупреждение → введите owner/repo и GitHub token → «Сохранить» → «⇅ Синхронизировать». Токен выдаётся со сроком — впишите дату в поле «Годен до» (числами, день.месяц.год — хватит цифр, точки сами): за 7 дней напомним строкой внизу экрана, за 3 дня — отдельным окном. Список при этом цел (он в телефоне), встанет только отправка копии. Дальше само: отправка через пару секунд после каждого изменения, при открытии и раз в минуту, пока вкладка открыта. Кто позже изменил задачу — тот и прав. Пустой телефон общий список не стирает. Новый телефон: поставьте приложение, введите те же repo и токен, нажмите «⇅ Синхронизировать». При ошибке синка приложение само отправляет журнал ошибок на сервер в папку logs/ (только служебные данные, без текстов задач), не чаще раза в 15 минут.

Если что-то не так

  • Нет интернета в дороге — откройте приложение заранее дома.
  • После обновления выглядит по-старому — сверьте версию вверху экрана и обновите страницу дважды.
  • На новом телефоне пусто — нажмите «⇅ Синхронизировать».
  • Светофор красный со знаком «!» (жёлтый — нет сети, белый — версии разошлись) — тапните по нему.
  • Светофор долго жёлтый — слабая сеть, просто подождите.
  • Не вводится текст (iPhone) — обновите приложение до свежей версии.
  • Ошибка синка вида «Returned response is null» — обновите приложение.
