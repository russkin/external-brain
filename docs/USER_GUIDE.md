# Инструкция пользователя «Внешний мозг»

«Внешний мозг» — список дел: задачи строками, группы — отступом.
Плюс поиск, оценка времени, отмена изменений и страховка копиями.
Работает без интернета — список хранится прямо в телефоне
(в скрытом хранилище браузера). Для страховки есть резервное
копирование списка на сервер GitHub: укажите в приложении
репозиторий и токен (пункт меню «🔑 Репозиторий и токен»).
Копия пригодится при потере или смене телефона.

Открыть: https://russkin.github.io/external-brain/

## Установка

1. На телефоне откройте https://russkin.github.io/external-brain/
   (проверяется на Android и iPhone; планшет — «как получится»).
2. Android Chrome → меню ⋮ → «Добавить на главный экран».
   iPhone Safari → кнопка «Поделиться» → «На экран “Домой”».
3. Дальше открывайте приложение ярлыком — список виден сразу,
   интернет не нужен.

## Новая задача — пять способов

1. **Список пуст (первый запуск).** Есть пустая строка: наберите
  текст прямо в ней — задача уже создана, текст сохраняется сам.
2. **Enter в конце задачи** — новая пустая строка под ней, курсор в неё.
3. **Enter в начале задачи** — новая пустая строка над ней.
4. **Enter в середине задачи** — строка делится на две: хвост
  от курсора становится новой задачей ниже.
5. **Пустая строка** — задача без текста (заполните её позже,
  удалите Backspace'ом или кнопкой «✕ Удалить» справа от строки).

Потеря фокуса (тап мимо, сворачивание клавиатуры) ничего не создаёт —
строка уже задача, набранное сохраняется само.

## Выполнить и вернуть

- Проведите по задаче **влево** — зелёный флаг «✓ Выполнено».
  Задача зачеркнётся и уедет вниз, в раздел «Выполнено».
- Ошиблись — проведите по выполненной влево и нажмите «↩ Не выполнено»,
  задача вернётся обратно (если выполняли группу — вернётся вся группа).
- Тап по раскрытой строке закрывает флаг обратно.
- Выполненные задачи не перетаскиваются.

## Удаление задач

- **Выполненные** — кнопка 🗑 вверху или пункт меню
  «Удалить выполненные». Спросит подтверждение; если выполненных
  нет — ничего не произойдёт.
- **Обычная строка** — поставьте курсор в самое начало и нажмите
  Backspace: текст приклеится к задаче выше, а сама строка удалится.
- **Пустая строка** — Backspace в ней же: строка просто удаляется.
- Если вы стёрли весь текст, а потом нажали Backspace — строка
  удалится, стёртое не вернётся.
- Случайно удалили — стрелка ↩ вернёт всё обратно
  (удаление тоже отменяется).

## Группы

- Потяните задачу за точки ⠿ (родителя — за треугольник) вверх/вниз —
  она переедет. Родитель переезжает вместе с вложенными.
- Потяните за точки вправо/влево (у родителя — за треугольник) — задача войдёт в группу верхней
  или выйдет из неё (тоже вместе с вложенными). В группу — только
  сдвигом, пока тянете страница стоит на месте. Если родитель был
  свёрнут — он развернётся, задача останется видимой.
- Тапните по треугольнику родителя — вложенные спрячутся (треугольник
  станет остриём вправо ▶); тапните ещё раз — покажутся (остриё вниз ▼).
  У обычных задач без вложенных — точки ⠿. Кнопки 📁 и 📂 вверху прячут
  и показывают всё сразу.
- Тап по «Выполнено · N» — показать/скрыть выполненные (N — всегда все).
  Тоже отменяется стрелкой ↩.
- Вложенность видна отступом и оттенком поля.

## Время задачи

Проведите по задаче **вправо** (или тапните метку в углу поля) —
откроется окно со стрелками «Часы» и «Минуты». «Убрать» снимает
метку, «Отмена» ничего не меняет. Время видно меткой в правом
нижнем углу задачи, например `1ч 30м`. У родителя метка считается
сама — сумма времени вложенных (выполненные не считаются), но галочку
«Суммировать из вложенных» можно снять — тогда время ставится вручную,
как у обычной задачи.
Если раскрыт флаг «✓ Выполнено» — свайп вправо только закроет флаг.

## Поиск

Кнопка 🔍 вверху открывает внизу окно: поле + кнопки
Поиск / Отмена / Вверх / Вниз + счётчики («Совпадений: 5», «2/5»).
При пустом поле Поиск, Вверх и Вниз неактивны. Наберите текст
и нажмите Поиск — страница прыгнет к первой найденной задаче
(ищется везде, свёрнутое разворачивается, большие/маленькие буквы
и ё/е не важны). Найденная подсвечена зелёным. Кнопки Вверх/Вниз
ходят по совпадениям. Кнопка Enter на клавиатуре — то же, что Поиск.
Отмена закрывает окно: если ничего не искали —
страница вернётся назад, если искали — останется на найденной.

## Отмена изменений

Стрелки ↩ ↪ вверху отменяют и возвращают последнее изменение
(помнят 50 шагов, работают даже после перезагрузки приложения).
Отмена возвращает и сворачивание: свернули всё кнопкой 📁, нажали ↩ —
группы и секция вернутся как были. Разворот одной группы тапом —
тоже изменение: ↩ свернёт её обратно.

## Копии — страховка от потери

Всё хранится в браузере телефона. Если телефон потеряется —
данные пропадут. Поэтому есть копии:
- **Скользящая копия** делается сама при каждом сохранении
  (состояние на шаг назад). Пункт меню «♻ Восстановить копию задач».
- **Постоянная копия** — «вечная» точка, делается кнопкой
  «💾 Сделать постоянную копию» (только с вашего подтверждения;
  в копию попадают только задачи, без настроек и токена)
  и сама — при первом запуске новой версии приложения.
  Восстановление — «♻ Восстановить постоянную копию».
- Даты обеих копий видны в диагностике (ⓘ).
- Для надёжности включите синхронизацию (ниже) — тогда список
  живёт ещё и в облаке.

## Значки вверху экрана

- Верхний ряд: название и версия, ⇅ интернет (зелёный — есть сеть,
  серый — нет; рядом скорость, на iPhone пусто), квадратик-светофор
  (тап — отправить вручную), ⚙ меню.
- Светофор: зелёный — всё отправлено, жёлтый мигает — отправляется,
  красный — ошибка, серый — синк выключен (нет ключа). Знак «!» поверх
  квадратика: жёлтый — обычная ошибка (например, нет сети), белый —
  версии разошлись (конфликт). По любому «!» тапните, чтобы отправить
  ещё раз.
- Нижний ряд: 🔍 поиск, 📁 спрятать всё, 📂 показать всё,
  ↩ отменить, ↪ вернуть, 🗑 удалить выполненные.
- Внизу экрана строка: сколько задач, сколько выполнено, состояние синка.

## Меню ⚙

- **ⓘ Информация для диагностики** — сведения о приложении одной
  страницей. Кнопки OK и Поделиться. Если что-то не работает —
  нажмите Поделиться и пришлите текст.
- **⇅ Синхронизировать** — отправить и забрать список вручную
  (обычно не нужно, всё идёт само).
- **📲 Установить приложение** — подсказка про установку.
- **📤 Поделиться списком** — текст задач (отправить или скопировать).
- **🔗 Поделиться приложением** — ссылка на приложение.
- **📖 Инструкция** — эта страница (работает без интернета).
- **📋 Информация о версиях** — вся история версий от первой до текущей,
  у каждой — главное изменение одной строкой (работает без интернета).
- **🧹 Очистка** — раскрывается: «Удалить выполненные» (убрать всё
  выполненное, спросит подтверждение) и «Удалить мёртвые (сжать)» —
  могилы удалённых сжимаются в короткие метки (файл худеет, живые
  и выполненные целы). Спросит дважды; лучше сначала синкнуть все
  устройства. Забытые устройства воскресить удалённое не смогут.
- **💾 Резервная копия** — раскрывается: три пункта про копии (выше).
- **🔑 Репозиторий и токен** — только для администратора. Сначала
  предупреждение, потом окно: три поля (репозиторий, токен, срок действия
  токена) и кнопки Сохранить/Отмена.

## Синхронизация (необязательно)

Без неё всё работает на одном телефоне — этого достаточно.
Синк нужен для двух вещей: страховка списка в облаке и перенос
на новый телефон.

Включение (один раз): ⚙ → «🔑 Репозиторий и токен» →
подтвердите предупреждение → введите `owner/repo` и GitHub token →
«Сохранить» → «⇅ Синхронизировать».

Токен на GitHub выдаётся со сроком действия — он виден при создании.
Впишите дату в поле «Годен до» (числами, день.месяц.год — достаточно
набирать цифры, точки подставятся сами): за 7 дней приложение напомнит строкой
внизу экрана, за 3 дня — отдельным окном (раз в день). Сам список при
этом никуда не денется (он хранится в телефоне), встанет только отправка
копии в облако. Если срок всё же вышел — ошибка синка так и скажет:
«похоже, токен истёк».

Дальше само: отправка через пару секунд после каждого изменения,
при открытии и раз в минуту, пока вкладка открыта.
Если не ушло — приложение повторит само.

Два правила:
- Кто позже изменил задачу — тот и прав.
- Пустой телефон общий список не стирает — он всё заберёт себе.

Новый телефон: поставьте приложение, введите те же repo и токен,
нажмите «⇅ Синхронизировать» — список подтянется.

## Если что-то не так

- Нет интернета в дороге — откройте приложение заранее дома.
- После обновления выглядит по-старому — сверьте версию вверху
  экрана и обновите страницу дважды.
- На новом телефоне пусто — нажмите «⇅ Синхронизировать».
- Светофор красный со знаком «!» (жёлтый — нет сети, белый — версии разошлись) — тапните по нему.
- Светофор долго жёлтый — слабая сеть, подождите.
- Не вводится текст (iPhone) — обновите приложение до свежей
  версии: в старых было запрещено выделение в поле, из-за этого
  клавиатура открывалась, а буквы не печатались.
- Ошибка синка на iPhone вида «Returned response is null» —
  обновите приложение: в старых версиях запросы шли через
  технический слой, который Safari не пропускал.
