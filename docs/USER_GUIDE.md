# Инструкция пользователя «Внешний мозг»

Простой список дел: задачи — строками, группы — отступом, выполненное —
свайпом. Работает офлайн, устанавливается без Play Market.

Открыть: https://russkin.github.io/external-brain/

## Установка

1. На телефоне/планшете откройте https://russkin.github.io/external-brain/
2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

## Главный экран

Каждая строка: слева точки ⠿, правее — поле задачи (многострочное, растёт
за текстом). Новая задача — через Enter в строке: пустое поле встаёт
под ней; у родителя с дочерними — сразу на их уровне (новая станет
ещё одной дочерней), у обычной задачи — на её уровне (набрали + Enter —
задача встала туда же,
поле поехало ниже). Если курсор в начале текста задачи — Enter вставляет
пустое поле над ней на её же отступе. Цепочка вниз: дети набираются подряд с тем же
отступом, влево — сдвигом за точки. Набрали текст и просто убрали
фокус (тап мимо, свернули клавиатуру) — задача создаётся так же,
без Enter; поле после этого гаснет, новое вызывается Enter в любой
строке. Если в другом месте уже набран незавершённый текст — Enter
в строке сначала создаёт эту задачу на её прежнем месте (иначе поле
просто переезжает сюда), и только потом открывает новое поле под строкой.
Тапы по строкам, флагам
и точкам — их собственные жесты, они поле не трогают.
Отдельного пустого поля
при длинном списке нет; при пустом списке или одной задаче оно
всегда внизу и так.
Пустое поле тоже умеет: свайп-флаг ✓ (с текстом — создать и выполнить,
без текста — убрать поле вниз), сдвиг за точки (свой отступ), перетаскивание
(при переносе встаёт на отступ соседа сверху, как задачи),
Backspace в пустом поле — убрать его вниз.

- **Точки — перетаскивание**: тяните вверх/вниз — строка едет, соседи
  разъезжаются. Родитель едет вместе с вложенными. Выполненные не таскаются.
  Перестановка (место и отступ) пишется в историю: ↩ возвращает задачу
  (и пустое поле) на место, а не удаляет. Взялись за точки — клавиатура
  сразу закрывается (набранный текст не теряется); курсор в конец поля
  возвращается только после переноса самого этого поля, чужой жест
  (свайп родителя) фокус не возвращает.
- **Точки — сдвиг вправо/влево**: задача входит в группу верхней (отступ)
  или выходит из неё. Новое поле начинается без отступа; в группу входит
  только сдвигом за точки.
- **Тап по точкам родителя** — свернуть/развернуть вложенные.
- **Свайп строки справа налево** — зелёный флаг «✓ Выполнено»: родитель
  уводит всю ветку (дети тоже отмечаются и переезжают вместе с ним).
  Выполненная зачёркивается и спускается под поле ввода
  (новые — выше старых). Свайп выполненной — флаг «↩ Не выполнено»:
  родитель возвращается вместе со всей веткой — дети возвращаются
  к нему в невыполненные. Ветка без живого родителя возвращается
  без отступа (вложенность внутри сохраняется) и без зачёркивания.
- **↩ ↪ в шапке** — отмена/возврат последних изменений (50 шагов).
  Enter делится на два шага: сначала уходит новое пустое поле
  (задача с текстом остаётся), затем — сама задача. Создание
  по потере фокуса — один шаг: задача уходит, текст возвращается
  в поле. Вызов поля
  через Enter в строке — тоже шаг: отмена убирает поле
  и возвращает курсор в конец задачи.
- Уровень вложения виден отступом и оттенком поля.

Внизу — строка статуса: счётчики + состояние синка.

## Кнопки вверху экрана

Верхний ряд (слева направо): название + версия, ⇅ интернет,
квадратик-светофор синка (тап — отправить вручную), ⚙ меню.
Нижний ряд: 📁 свернуть все группы, 📂 развернуть все, ↩ отменить,
↪ вернуть, 🗑 удалить выполненные (с подтверждением).

Светофор: зелёный — всё отправлено, жёлтый мигает — идёт отправка,
красный — ошибка, серый — синк выключен (нет ключа).

## Меню шестерёнки ⚙

- **ⓘ Информация для диагностики** — версия, счётчики, состояние синка. Пришлите этот
  текст, если что-то не работает.
- **⇅ Синхронизировать** — отправить и забрать общий список вручную (обычно не нужно).
- **📲 Установить приложение** — подсказка про установку.
- **📤 Поделиться списком** — текст задач (в буфер обмена или шаринг).
- **Удалить выполненные** (с подтверждением) — то же, что 🗑 в шапке.
- **Настройки синхронизации**: поля `owner/repo` и GitHub token (хранится только
  на этом устройстве), кнопка «Сохранить».
- Ссылка **«Инструкция»** — эта страница (доступна и офлайн).

## Синхронизация между устройствами (необязательно)

Без неё каждое устройство живёт своим списком (для одного телефона достаточно).

Чтобы списки были общими, **на каждом устройстве**: ⚙ → введите `owner/repo`
(по умолчанию уже `russkin/external-brain`) и GitHub token → «Сохранить» →
«⇅ Синхронизировать».

Дальше всё само: отправка идёт через 2 секунды после каждого изменения,
при открытии приложения и раз в минуту. Если отправка не удалась — приложение
повторит само ещё 5 раз через 2 секунды.

Простые правила:

- Кто позже изменил — тот и прав. Не правьте одну задачу с двух устройств в одну минуту.
- Пустое устройство общий список не стирает — оно, наоборот, всё заберёт себе.
- Держите все устройства на свежей версии (номер вверху экрана).
- Светофор долго жёлтый — дело в слабой сети, просто подождите.

## Если что-то не так

- Список не открылся без интернета — откройте приложение заранее дома: страница
  и данные уже в кэше.
- После обновления что-то выглядит по-старому — сверьте версию вверху экрана
  с latest в репозитории; при расхождении обновите страницу дважды.
- На новом устройстве пусто после ввода ключа — нажмите «⇅ Синхронизировать»
  и проверьте строку статуса внизу.
