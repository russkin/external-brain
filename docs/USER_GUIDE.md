# Инструкция пользователя «Внешний мозг»

Простой список дел по «Джедайским техникам»: собирай всё в инбокс, проясняй,
каждый день съедай лягушку, слонов режь на бифштексы.

Открыть: https://russkin.github.io/external-brain/

## Установка

1. На телефоне/планшете откройте https://russkin.github.io/external-brain/
2. Android Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Держите приложение открытым — после разблокировки список виден сразу, интернет не нужен.

## Главный экран

Сверху вниз:

- **Фокус дня** (синяя рамка) — главная задача сегодня: сначала лягушка,
  иначе первое следующее действие, иначе первый инбокс. Пусто и тихо — можно отдыхать.
- **Строка ввода + «В инбокс»** — любая мысль сразу сюда. Enter тоже работает.
  Правило джедая: инбокс к вечеру — пустой.
- **Инбокс — прояснить** — неразобранное. У каждой мысли кнопки:
  **Next** (следующее действие), **Wait** (жду), **Someday** (когда-нибудь),
  **Proj** (привязать проект и сразу в следующие), **X** (удалить).
- **Следующие** — действия. Кнопки: **Frog/Unfrog** (назначить лягушкой дня),
  **+1** (съесть бифштекс), **Slices** (нарезать слона: сколько кусков),
  **X** (удалить). Галочка слева — готово.
- **Ожидание** — то, что зависит от других. Кнопки: вернуть в следующие, удалить.
- **Когда-нибудь** — идеи на потом. Кнопки те же.
- **Готово** — последние 30 выполненных. Можно вернуть (Reopen) или удалить.

Внизу — строка статуса: счётчики инбокса и следующих + состояние синка.

## Кнопки вверху экрана

Слева направо:

- **Название + версия** (например, v1) — сверяйте версии на устройствах.
- **⇅** — интернет (индикатор).
- **Квадратик-светофор** — состояние синхронизации: зелёный — всё отправлено,
  жёлтый мигает — идёт отправка, красный — ошибка, серый — синк выключен (нет ключа).
  Тап — отправить вручную.
- **⚙ (шестерёнка)** — меню (см. ниже).

## Меню шестерёнки ⚙

- **ⓘ Информация для диагностики** — версия, счётчики, состояние синка. Пришлите этот
  текст, если что-то не работает.
- **⇅ Синхронизировать** — отправить и забрать общий список вручную (обычно не нужно).
- **📲 Установить приложение** — подсказка про установку.
- **📤 Поделиться списком** — текст фокуса и групп (в буфер обмена или шаринг).
- **Удалить выполненные** (с подтверждением) — чистка раздела «Готово».
- **Настройки синхронизации**: поля `owner/repo` и GitHub token (хранится только
  на этом устройстве), кнопка «Сохранить».
- Ссылка **«Инструкция»** — эта страница (доступна и офлайн).

## Лягушки и слоны (коротко)

- **Лягушка** — самая неприятная задача дня. Назначьте кнопкой Frog — она встанет
  первой в «Следующих» и попадёт в «Фокус дня». Съешьте с утра — день удался.
- **Слон** — задача больше 1–2 часов. Кнопка Slices → введите число бифштексов
  (например, 5). Кнопка +1 съедает по куску, счётчик показывает (2/5).
  Последний кусок закрывает задачу сам.
- **Еженедельный обзор**: откройте «Когда-нибудь» и «Ожидание», часть — в следующие,
  часть — удалить. Инбокс — в ноль.

## Синхронизация между устройствами (необязательно)

Без неё каждое устройство живёт своим списком (для одного телефона достаточно).

Чтобы списки были общими, **на каждом устройстве**: ⚙ → введите `owner/repo`
(по умолчанию уже `russkin/external-brain`) и GitHub token → «Сохранить» →
«⇅ Синхронизировать».

Дальше всё само: отправка идёт через 2 секунды после каждого изменения,
при открытии приложения и раз в минуту. Если отправка не удалась — приложение
повторит само ещё 5 раз через 2 секунды.

Простые правила:

- Кто позже изменил — тот и прав. Не правьте одну задачу с двух устройств в одну минуту.
- Пустое устройство общий список не стирает — оно, наоборот, всё заберёт себе.
- Держите все устройства на свежей версии (номер вверху экрана).
- Светофор долго жёлтый — дело в слабой сети, просто подождите.

## Если что-то не так

- Список не открылся без интернета — откройте приложение заранее дома: страница
  и данные уже в кэше.
- После обновления что-то выглядит по-старому — сверьте версию вверху экрана
  с latest в репозитории; при расхождении обновите страницу дважды.
- На новом устройстве пусто после ввода ключа — нажмите «⇅ Синхронизировать»
  и проверьте строку статуса внизу.
